Confidentialité

Pas de compte, pas de publicité, pas de mesure d'audience, pas de traceur. Ta progression (or, objets, talents, réglages) est enregistrée sur ton appareil (et, sur iPhone, ton meilleur temps dans ton iCloud).
Classements en ligne du mode infini (versions web et Android) — l'app iPhone n'envoie rien à notre serveur : elle utilise seulement les classements Game Center d'Apple. Dans les versions web et Android, à la fin d'une partie en mode infini, le jeu envoie à notre serveur (Cloudflare) ton pseudo (celui des Paramètres, que tu choisis librement), ton temps et un identifiant tiré au hasard sur ton appareil, pour garder ton meilleur temps. Aucune autre information (nom, e-mail, position, contacts…) n'est envoyée. Ces données servent seulement à afficher les classements. Pour faire retirer ton pseudo et tes temps, écris-nous (voir Contact). Endless leaderboards (web and Android versions; the iPhone app sends nothing to our server and only uses Game Center): your chosen nickname, your time and a random device identifier are sent to our server only to display rankings; ask us by e-mail to have them removed.
Multijoueur dans le navigateur — le serveur relaie les actions de jeu entre les joueurs d'une même salle, avec le pseudo de chacun, le temps de la partie ; rien n'est conservé ensuite.
Game Center (iPhone) — si tu es connecté à Game Center, tes succès, tes scores de classement et les parties à plusieurs passent par Apple, selon la politique de confidentialité d'Apple. Le jeu ne reçoit que ton pseudo Game Center pour l'afficher à tes coéquipiers.
Parties à plusieurs dans le navigateur — un relais (Cloudflare) transmet seulement les commandes de jeu entre les joueurs d'une même partie, identifiée par un code de 4 lettres. Aucun nom, aucune adresse e-mail, rien n'est conservé une fois la partie terminée. Cloudflare peut traiter techniquement ton adresse IP pour acheminer les messages.

No personal data is collected: no account, no ads, no analytics, no tracking. Progress is stored on your device only. Game Center features go through Apple. Browser co-op uses a Cloudflare relay that only forwards game inputs between players of a room and keeps nothing.
