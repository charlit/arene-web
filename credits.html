Confidentialité

Aucune donnée personnelle collectée. Pas de compte, pas de publicité, pas de mesure d'audience, pas de traceur. Ta progression (or, objets, talents, réglages) est enregistrée uniquement sur ton appareil (et, sur iPhone, ton meilleur temps dans ton iCloud).
Game Center (iPhone) — si tu es connecté à Game Center, tes succès, tes scores de classement et les parties à plusieurs passent par Apple, selon la politique de confidentialité d'Apple. Le jeu ne reçoit que ton pseudo Game Center pour l'afficher à tes coéquipiers.
Parties à plusieurs dans le navigateur — un relais (Cloudflare) transmet seulement les commandes de jeu entre les joueurs d'une même partie, identifiée par un code de 4 lettres. Aucun nom, aucune adresse e-mail, rien n'est conservé une fois la partie terminée. Cloudflare peut traiter techniquement ton adresse IP pour acheminer les messages.

No personal data is collected: no account, no ads, no analytics, no tracking. Progress is stored on your device only. Game Center features go through Apple. Browser co-op uses a Cloudflare relay that only forwards game inputs between players of a room and keeps nothing.
